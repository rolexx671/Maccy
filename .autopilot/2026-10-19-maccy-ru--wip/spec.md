# Спецификация: Maccy на русском + DMG

## Задача
Пользователь хочет свой форк Maccy, где всё по-русски, собранный в DMG, и понятную инструкцию, как его поставить и настроить.

## Решение
- **R09i** — приложение всегда на русском, даже на английской macOS: язык `ru` принудительно задаётся в домене приложения при самом раннем запуске (`AppleLanguages = ["ru"]`), так что русскими становятся и строки сторонних пакетов (Settings, KeyboardShortcuts, Sparkle — у них есть `ru`). Плюс `CFBundleDevelopmentRegion = ru` как запасной вариант.
- **R03** — интерфейс: всё, что видит пользователь, — по-русски. Существующий `ru.lproj` полон; исправить опечатку «дейстительно». Окно «О программе»: благодарности перевести, ссылки в тексте искать по подстроке, а не жёсткими `NSRange`.
- **R04** — команды «Быстрых команд» (Intents: заголовки, описания, параметры, сущность «Элемент буфера», ошибка «не найден», диалог запроса номера) локализуются через `Localizable.strings` (ключ — английский текст, в `en` и `ru`).
- **R05** — документация по-русски на месте: `README.md`, `docs/keyboard-shortcut-password-fields.md`, `Designs/Copies.txt`, шаблоны issue в `.github/ISSUE_TEMPLATE/*.yml` (только видимые тексты, ключи YAML не трогать). Ссылки и картинки сохраняются; в README добавляется пометка, что это русский форк, со ссылкой на оригинал.
- **R10i** — автообновление отключено: Sparkle не запускает проверки, `SUFeedURL` убран/выключен (`SUEnableAutomaticChecks = NO`), переключатель «Проверять обновления» и кнопка «Проверить сейчас» скрыты из настроек. Иначе обновление поставит английский оригинал.
- **R06 / R11i** — DMG: Release-сборка без Developer ID (ad-hoc подпись `-`), песочница и hardened runtime сохраняются, если ad-hoc их допускает. Скрипт `scripts/build-dmg.sh` воспроизводимо собирает `.app` и `Maccy-ru-<версия>.dmg` (окно с `Maccy.app` и ярлыком `Applications`) через `hdiutil`; результат в `build/`.
- **R07 / R08** — инструкция `INSTALL.ru.md` в корне: установка из DMG, обход Gatekeeper («Всё равно открыть» в «Конфиденциальность и безопасность» / `xattr -dr com.apple.quarantine`), разрешение «Универсальный доступ» для вставки, горячая клавиша (⇧⌘C), основные настройки по вкладкам, «Быстрые команды», удаление, конфликт с оригинальным Maccy.

- **G01** — изменения коммитятся и отправляются (`git push`) в форк `rolexx671/Maccy`, ветка `master`; DMG в git не попадает.

## Решения по реализации
- Bundle ID `org.p0deje.Maccy` и имя «Maccy» не меняются — история и настройки пользователя, если он уже ставил Maccy, сохраняются. Цена: нельзя держать рядом оригинал (в инструкции).
- Языки других стран из проекта не удаляются: принудительный `ru` их и так не покажет, а удаление ломает будущие слияния с upstream.
- `.gitignore` получает `build/`.

## Вне рамок
| Что | Почему |
|---|---|
| комментарии в коде, сообщения логов (`NSLog`, `fatalError`) | пользователь их не видит |
| `LICENSE` | юридический текст MIT — перевод не имеет силы, остаётся оригинал |
| `appcast.xml`, бинарные макеты в `Designs/` (pxd, psd, mov, sketch) | служебные данные и картинки, не текст |
| перевод «всего» сужен до видимого пользователю тексту и документации — строки выше | будет в отчёте как сознательное сужение |
| нотаризация Apple | нет Developer ID на машине |
| публикация в GitHub Releases | пользователь: «DMG локально без релиза» |
